PG Assessment Tool – Ophthalmology

Project Overview

The PG Assessment Tool – Ophthalmology is a web-based application designed to assess and evaluate the knowledge and performance of postgraduate medical interns in the field of Ophthalmology.

The platform provides a structured assessment environment with role-based access for Admins, Faculty, and Interns. It aims to simplify assessment management, streamline evaluation, and maintain organized records of intern performance.

Key Features

- Role-Based Access: Separate access for Admin, Faculty, and Intern roles.
- Assessment Management: Manage and conduct postgraduate assessments.
- Intern Management: Maintain intern details and assessment records.
- Performance Evaluation: Track and evaluate assessment performance.
- Authentication: Secure login with JWT-based authentication.
- Centralized Database: Store and manage application data using MySQL.

User Roles

- Admin: Manages users and oversees the assessment platform.
- Faculty: Handles assessments and evaluates interns.
- Intern: Accesses assessments and views performance-related information.

Technology Stack

- Frontend: React.js, HTML, CSS, JavaScript
- Backend: Node.js, Express.js
- Database: MySQL
- Authentication: JSON Web Token (JWT)
- Access Control: Role-Based Access Control (RBAC)

Project Objective

To provide a centralized digital platform for conducting and managing Ophthalmology postgraduate assessments, making the evaluation process more organized, accessible, and efficient.
